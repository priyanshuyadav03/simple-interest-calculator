# Simple Interest Calculator

## Description
A simple interest calculator that computes interest based on principal, rate, and time.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Calculate simple interest easily
- Input: Principal amount, Rate of interest, Time period
- Output: Simple interest and total amount

## Usage
1. Enter the principal amount
2. Enter the rate of interest (% per year)
3. Enter the time period (in years)
4. Get the simple interest instantly

## Example
- Principal = $1000
- Rate = 5%
- Time = 3 years
- Simple Interest = (1000 × 5 × 3) / 100 = **$150**
